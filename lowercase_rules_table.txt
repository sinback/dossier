  NOTES/specific evidence on annotations:
  - 'o' entry "undefined" and "weak": omitted if pen lifted before 'o', y-center if previous letter's exit is y-center, y-bottom if previous letter's exit was y-bottom. See "Colonies" (uppercase 'C' has a pen lift prior to 'o', "Despotism" ('p's y-bottom exit becomes o y-bottom entry), "of" (initial 'o' has no entry), "form", ('f's y-center exit becomes o y-center entry), etc.
  - 'r' entry "weak": "naturally" a y-bottom (as evidenced by beginning-of-word behavior), but will be y-center if preceeded by a y-center exit
  - 'o' y-center exit is very strong: stronger than {'l', 's', 'r'}, see "Colonies", "most", "transporting"
  - 's' data applies to modern "s" glyph (in Copperplate, there's a secondary 's' glyph sometimes used at beginning of words, always used prior to a second 's'; we haven't captured this one yet
  - 'b' exit stronger than 'e' entry, see "be"
  - 'r' exit typically "low_exit"/"rule.y-bottom", but it's been observed to have a rule.y-center "high_exit" in some words, such as "truths" and one instance of "rights" (another instance of "rights" has a low_exit, though. Let's pretend 'r' is low_exit always for simplicity
